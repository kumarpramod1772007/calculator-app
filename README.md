# Better Calculator App

A simple, responsive, and modern **Calculator App** built with **HTML, CSS, and JavaScript**.  
This app supports basic arithmetic operations, percentage calculation, decimal points, and includes **Clear** and **Delete** buttons.

---

## Features

- Simple and clean user interface
- Responsive design (works on mobile and desktop)
- Supports operations: `+`, `-`, `*`, `/`, `%`
- Clear (`C`) and Delete (`DEL`) functionality
- Error handling for invalid expressions
- Option to use as **PWA** (Progressive Web App)
